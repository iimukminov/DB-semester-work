## 1. Архитектура
* **Хранилище:** Таблица `marketplace.tasks`.
* **Транзакционность:** Создание заказа (`marketplace.orders`) и постановка задачи происходят строго в одной транзакции (`@Transactional`).
* **Конкурентность:** Два независимых воркера безопасно разбирают задачи с помощью блокировки `FOR UPDATE SKIP LOCKED`.
* **Код:** Вся реализация лежит [тут](../../message-broker)

## 2. Нагрузка и Лаг
Продьюсер генерирует ~300 задач/сек. Воркеры обрабатывают их с задержкой 50мс.
Поскольку приток задач превышает пропускную способность воркеров, лаг (время ожидания в очереди) стабильно растет.

**Логи (рост лага):**
```text
=== СТАТИСТИКА ОЧЕРЕДИ ===
Лаг очереди: 10,41 сек
Пропускная способность: 2 задач/сек (сумма 2-х воркеров)
==========================
Worker-2 взял задачу ID: 151 с приоритетом 100
Worker-1 взял задачу ID: 158 с приоритетом 100
Worker-2 взял задачу ID: 160 с приоритетом 100
Worker-1 взял задачу ID: 166 с приоритетом 100
Worker-2 взял задачу ID: 169 с приоритетом 100
Worker-1 взял задачу ID: 171 с приоритетом 100
Worker-2 взял задачу ID: 172 с приоритетом 100
=== СТАТИСТИКА ОЧЕРЕДИ ===
Лаг очереди: 12,38 сек
Пропускная способность: 3 задач/сек (сумма 2-х воркеров)
==========================
```

## 3. Приоритеты

Генерируется 20% срочных задач (Priority 100) и 80% обычных (Priority 0). Срочные задачи всегда забираются воркерами вне очереди.

**Логи (перехват срочных задач):**

```text
Worker-1 взял задачу ID: 408 с приоритетом 100
Worker-2 взял задачу ID: 2 с приоритетом 0
Worker-1 взял задачу ID: 3 с приоритетом 0
Worker-2 Ошибка при обработке задачи ID: 4290
```

## 4. Доп. механизмы

* **Retry:** При сбое счетчик `attempts` растет, задача откладывается на 5 минут. После 3 ошибок статус меняется на `failed`.
* **Борьба с Bloat (Агрессивный Autovacuum):** Из-за частых `UPDATE` таблица быстро раздувается мертвыми строками (MVCC). Для поддержания скорости выборки задач на таблицу `tasks` настроен агрессивный автовакуум, который срабатывает при изменении всего 1% строк:

```sql
ALTER TABLE marketplace.tasks SET (
    autovacuum_vacuum_scale_factor = 0.01,
    autovacuum_vacuum_threshold = 50,
    autovacuum_analyze_scale_factor = 0.01,
    autovacuum_analyze_threshold = 50
);
```
